# Southside 1927

A pixel-art Prohibition simulation set on one Chicago block in 1927. Walk the street, take on eight history-based missions, play a mini-game at the end of each, and unlock the Vane house finale.

It's a single static page (`index.html`) with no build step, so any static host can serve it.

## Run it locally

Open `index.html` in a desktop browser.

## Deploy on Vercel

1. Import this repository at vercel.com/new.
2. Leave every setting at its default (Framework Preset: Other, no build command) and click **Deploy**.
